# desktop-file-generator
a `.desktop` file generator for linux and BSD like systems

# how to use
## step 1: install
`git clone https://github.com/sbusiedcake7945/desktop-file-generator.git && cd desktop-file-generator`

## step 2: give it access
`chmod +x dfg`

## step 3: run
`./dfg`

# requirements
`python3`, any DE/WM that can run .desktop files
